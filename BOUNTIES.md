# Bounties — MyZubster Web

This repository follows the canonical [MyZubster Bounty System](https://github.com/MyZubster-Ecosystem/myzubster/blob/main/BOUNTIES.md).

## Eligible scope

Web bounties may cover frontend implementation, accessibility, performance, API/IPFS integration, testing, documentation and deployment reproducibility.

## Acceptance

A web bounty should define the target screen/behavior, supported environment, API contract and reproducible build/test evidence.

## Security

Do not expose server secrets in client bundles. Public IPFS content must remain sanitized; the web client is not the authority for bounty approval or external settlement.

## Reward truth

MYZ in the current core platform is an internal reward/accounting ledger. Issue/PR/merge is not proof of an external payment.

## Issues

Use this repository's GitHub issues and link the implementation PR to the selected bounty.
