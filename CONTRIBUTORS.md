# MyZubster Digital Identities

This file documents the voluntary **MyZubster Digital Identities** of contributors to MyZubsterWeb.

> **Important**: This is **not KYC, SPID/CIE, a government identity, or a qualified electronic signature**. Never publish private keys, seed phrases, credentials or unnecessary personal data. A public alias is sufficient.

## How to add your identity

1. Fork this repository
2. Add your identity block below (see template)
3. Submit a pull request

## Template

```text
IDENTITY
GitHub alias: @your-handle
Public display name/alias: <optional>
Main contributions: <issue/PR links>
Public profile links: <optional>
```
